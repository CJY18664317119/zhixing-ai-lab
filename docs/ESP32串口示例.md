# ESP32 串口协议
默认 115200 波特，UTF-8，每条一行（LF）。

- 文字：FORWARD / LEFT / RIGHT / STOP
- 数字：1 / 2 / 3 / 0
- JSON：{"cmd":"FORWARD"}

建议先用文字协议。固件必须在启动时停车、非法指令时停车、最近一次有效指令超过 1000ms 时停车。串口缓冲应限制行长（如 128 字节），不能将任意字符串直接解释为程序。电机引脚取决于实际驱动板，因此不提供通用烧录固件。

应用正常运行期间画面 1.5 秒无更新会尝试发送 STOP；控制默认关闭、未连接串口不能开启。急停解除不会自动恢复控制，需要手动重新开启。
