# 智行 AI Lab · 课堂快速开始

## 当前交付范围
可运行的 Next.js 教学界面与本地 Python 引擎源代码，不是已经验收的 Windows 安装包。Linux 沙箱无法完成 Windows / ESP32 实机验收。

## Windows 首次安装（联网）
需要 Windows 10/11、Python 3.11、Node.js 22 和 pnpm 10。运行 `powershell -ExecutionPolicy Bypass -File scripts/setup-windows.ps1`。脚本安装 PyTorch / Ultralytics 及分类、检测基础权重，再构建界面。建议磁盘剩余 8GB 以上。

## 离线启动
运行 `powershell -ExecutionPolicy Bypass -File scripts/start-windows.ps1`，用 Edge 或 Chrome 打开 http://localhost:3000 。浏览器项目保存在 IndexedDB，模型与训练任务位于 `%USERPROFILE%/ZhixingAILab`。避免清除网站数据，定期导出项目备份。

## 实验
1. 创建图片分类或目标检测项目。
2. 导入图片，添加类别。建议每类至少 30 张，覆盖不同光照与角度。
3. 分类：选择类别并保存；检测：拖动绘制框，选中类别。当前框支持删除重画，不支持直接移动缩放。
4. 一键划分后启动真实训练。分类数据每类应覆盖训练和验证集合。
5. 运行图片、视频当前帧或摄像头当前帧。当前版本为单帧识别，不是持续实时推理。
6. 用 Edge / Chrome 手动选择串口。先发送停车测试，再映射动作。仅当手动开启小车控制且置信度达标才发送动作。
7. 模型页可导出 ONNX，项目页可导入 JSON 备份。

## 安全
急停按钮尝试发送 STOP；断线时不能保证送达。ESP32 固件必须独立处理指令超时并停止电机，未收到指令 1000ms 停车。必须架空车轮测试，不可仅靠软件安全机制保护人身或设备。
