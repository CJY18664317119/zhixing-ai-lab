# 智竞 AI Arena · 精简版

面向高中生的四个功能：**数据标注 → 模型训练 → 模型运行 → 结果输出**。
不包含账号、赛事、评分、代码工作台等模块。

- 数据标注：上传图片或摄像头采集，给图片打类别；目标检测任务可拖拽画框。
- 模型训练：在浏览器里真实训练 —— 图片压成 20×20 灰度网格 + RGB 均值（403 维特征），按类别求质心，用留出的验证图片算准确率、召回与混淆矩阵。指标全部来自真实计算，没有任何预置数值。
- 模型运行：选已有样本、上传新图片或开摄像头实时识别，输出类别、置信度与检测框。
- 结果输出：识别结果按“类别 → 指令”映射实时经串口（Web Serial，115200）发给 ESP32 小车，同时落库、可导出 CSV / JSON。

## 运行

```bash
pnpm install
pnpm run db:setup     # 装依赖 + 应用版本化迁移
pnpm dev              # http://localhost:3000
```

数据库连接串由平台通过环境变量 `DATABASE_URL` 注入，不要写进代码。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST/PATCH/DELETE | `/api/samples`、`/api/samples/[id]` | 样本的增删改查（图片以 data URL 存库，单张 ≤ 2 MB，上限 200 张） |
| GET/PUT | `/api/labels` | 类别名称列表（至少 2 个，最多 20 个） |
| GET/POST/DELETE | `/api/models` | 训练产物：质心模型 + 留出集指标 |
| GET/POST | `/api/runs` | 运行记录；`?format=csv` 导出 CSV |

## 算法说明（重要）

内置模型是**真实可解释的轻量分类器**，不是深度学习：

1. 每张图片缩放为 64×64 后提取特征：20×20 灰度网格（400 维）+ RGB 全局均值（3 维）；
2. 每个类别求特征均值得到“质心”，共 N 个质心；
3. 推理时算特征到各质心的距离，最近者胜出；置信度由最邻近两个质心的距离差软化得到；
4. 每个类别 ≥ 4 张时，自动留出约 25% 的图片做验证，准确率/召回/混淆矩阵都由这些留出图片算出；样本不足时显示“未评估”，不会编造数字；
5. 目标检测任务用同一套质心做**滑窗分类 + 非极大值抑制**得到候选框（教学用，非深度检测器）。

想换成深度学习模型时，只需要替换 `lib/ml/engine.ts` 里的训练与推理实现，接口保持一致。

## 串口协议（结果输出 → 小车）

行式 JSON，一行一条，`\n` 结尾：

```json
{"v":1,"cmd":"FORWARD","speed":35}
```

- 内置指令：`FORWARD` `BACKWARD` `LEFT` `RIGHT` `STOP` `SPEED` `HEARTBEAT`；
- 平台侧速度硬上限 60%，心跳每 500 ms 一条；
- 示例固件 `public/firmware-examples/esp32.ino` 默认**禁用所有移动动作**，需要你按自己的电机驱动补齐 PWM 与动作映射；
- 固件必须实现 1.5 秒心跳超时停车，网页关闭或断线时小车会自动停下；
- 串口需要桌面版 Chrome / Edge、安全上下文和用户主动授权；嵌入式预览窗口可能拿不到串口/摄像头权限，此时请在独立窗口打开。

## 已知边界

- 训练与推理都在浏览器里跑：样本量大时首次训练会慢，模型指标受特征表达能力限制；
- 串口和摄像头未做真机联调，示例固件也需要按你的硬件补齐；
- 图片以 data URL 存库，适合课堂规模（≤ 200 张 / 2 MB），不适合大规模数据集；
- 无账号体系，当前部署是单工作区共享，多人同时标注会互相影响。
